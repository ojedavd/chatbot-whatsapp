# AI Chatbot on WhatsApp

Companion repository for the published article in **USERS Magazine (RedUsers)**:  
📖 [Read publication on RedUsers](https://premium.redusers.com/library/publication/iu546)

## Overview

A Node.js implementation of an automated, intelligent WhatsApp assistant designed to handle dynamic conversational flows, state tracking, and automated customer/user interactions using .

## Key Features

- **Conversational Flows**: Modular dialog trees and dynamic response handling.
- **Session & State Management**: Efficient in-memory caching and message routing.
- **Media Support**: Automatic formatting and rich message support.
- **Production Integration**: Ready to hook into external APIs, webhooks, or LLM backends.

## Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the bot**:
   ```bash
   npm start
   ```

3. **Link WhatsApp**:
   Scan the generated QR code with WhatsApp on your mobile device.
